# Zdjęcia

Pliki pochodzą z materiałów dostarczonych przez właściciela projektu. **Przed publikacją potwierdź prawa do ich użycia.**

| Plik | Gdzie | Uwagi |
|------|-------|-------|
| `hero-aerial.jpg` | hero, galeria | 1148 px szerokości – na duże ekrany potrzebna wersja min. 2560 px lub krótka pętla wideo |
| `yamaha-gp1800r-brzeg.jpg` | flota, galeria | widoczna tablica rejestracyjna |
| `yamaha-gp1800r-plaza.jpg` | galeria, lokalizacja (zdjęcie poglądowe) | widoczna tablica rejestracyjna |
| `yamaha-fx.jpg` | flota, galeria | wygląda na materiał prasowy producenta – sprawdź licencję |
| `yamaha-vx.jpg` | flota, galeria | |
| `sea-doo-spark.jpg` | flota, „bez patentu”, galeria | niska rozdzielczość (588 px) |

Nie użyto: reklamy Sea-Doo z logo marki, zdjęcia ze znakiem wodnym innej wypożyczalni, zdjęcia z zawodów z logotypami
sponsorów, zrzutu ekranu strony stoczni (tylko inspiracja) oraz zdjęcia wyglądającego na wygenerowane przez AI.

Zdjęcia skuterów można też wgrać w panelu (/panel → Flota). Najlepiej poziome, min. 1600 px szerokości.
