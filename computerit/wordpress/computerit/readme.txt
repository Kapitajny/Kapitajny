=== computerit ===

Prosty, czarno-biały motyw WordPressa: logo computerit obok menu
(Strona główna, O mnie, Cennik, Portfolio, Kontakt), czarne napisy na białym tle.

== Instalacja ==

1. Wygląd → Motywy → Dodaj nowy motyw → Wyślij motyw na serwer.
   Wybierz plik computerit.zip, kliknij „Zainstaluj”, potem „Włącz”.

2. Strony → Dodaj nową. Utwórz 5 stron:
   Strona główna, O mnie, Cennik, Portfolio, Kontakt.

3. Ustawienia → Czytanie → „Twoja strona główna wyświetla”: Statyczna strona.
   Jako stronę główną wybierz „Strona główna”.

4. Ustawienia → Ogólne → Motto: „Technologia z nowej perspektywy”.
   Motto jest dużym nagłówkiem na stronie głównej.

5. Wygląd → Menu → utwórz menu, dodaj 5 stron w kolejności:
   Strona główna, O mnie, Cennik, Portfolio, Kontakt.
   Na dole zaznacz „Menu główne” i zapisz.

   (Dopóki tego nie zrobisz, motyw sam pokazuje Stronę główną
   oraz strony o adresach o-mnie, cennik, portfolio i kontakt.)
