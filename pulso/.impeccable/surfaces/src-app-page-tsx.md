## Direction contract

THESIS: The page is PULSO's media plan. Weeks run across, channels run down, every section is a flight placed on the plan. It refuses the centred dark hero over a row of service cards.

OWN-WORLD: Plan paper near-white with hairline week grid, ink-black type, four channel inks (cobalt Meta, amber Google, vermilion YouTube, teal TikTok). Booked = solid bar, tentative = dashed outline. One active marker only: the ink playhead. Archivo, wide for display, condensed caps for column heads, tabular figures everywhere. DEMO stamps as honest chrome.

STORY: Visitor sees how a plan is built before money is spent, believes fees and budget are separate and visible, books a consultation with the plan they sketched.
